# 포켓몬 던전 로그

포켓몬 지방을 돌아다니며 배지를 모으고 리그에 도전하는 **비상업 팬게임 로그라이크**입니다.
쓰러지면 처음부터 다시 시작하고, 판을 거듭할수록 도감·도전과제·스타팅 포켓몬·지방이 해금됩니다.

▶ 플레이: https://umgeunchan.github.io/pokemon-roguelike/

> 포켓몬스터와 관련된 이름·그림의 권리는 Nintendo / Creatures / GAME FREAK에 있습니다.
> 이 프로젝트는 수익을 내지 않는 팬 제작물이며, 데이터와 그림은 PokeAPI, PMD SpriteCollab, Pokémon Showdown에서 불러옵니다.

## 조작

| 키 | 동작 |
|---|---|
| W A S D | 이동 (문 앞에서 W를 누르면 건물에 들어감) |
| 방향키 | 그 방향으로 공격 |
| Space | 달리기(대시) |
| E | 말 걸기 · 상점 닫기 |
| M | 지방 지도 |
| Esc | 메뉴 (설정, 볼륨) |
| N | 소리 끄기/켜기 |
| F | 전체 화면 켜기/끄기 |
| H | 첫 판 안내 건너뛰기 |
| R | 결과 화면에서 다시 하기 |

휴대폰·태블릿에서는 왼쪽 스틱(이동), 오른쪽 스틱(공격)과 화면 버튼으로 조작합니다.

## 파일 구조

```
index.html            캔버스와 스크립트 불러오기 (순서대로 실행되니 순서를 바꾸지 말 것)
css/style.css         화면·터치 버튼 스타일
js/data/regions.js    지방 지도, 체육관 관장, 사천왕, 라이벌, 트레이너 종류
js/data/moves-items.js 타입, 도구, 상점, 기술머신, 숨은 조합, 전설 기술
js/progress.js        지방 해금, 도전과제
js/core.js            공통 도구, 저장소, 전역 상태, 데이터 불러오기, 난이도 상수
js/world.js           지방 지도 생성, 상자·전설 배치, 적 생성
js/run.js             경험치·레벨·진화, 새 판, 이어하기 저장
js/combat.js          피해 계산, 공격, 적 기술 패턴, 야생 출현, 전설
js/battle.js          트레이너·관장·사천왕·챔피언·라이벌 승부, NPC, 상점
js/update.js          매 프레임 진행: 이동, 충돌, 아이템 줍기
js/draw.js            필드 그리기
js/screens.js         메뉴·지방 선택·스타팅 선택·도전과제·결과 화면
js/input.js           키보드·마우스 입력
js/account.js         Google·게스트 계정, Firebase 동기화, 시작 화면
js/touch.js           터치 조작
js/audio.js           합성 배경음과 효과음
js/main.js            게임 루프, 시작
firestore.rules       Firestore 보안 규칙 (자기 문서만 읽고 쓰기)
```

수정 후 배포할 때는 `index.html`의 `?v=` 숫자를 올려야 브라우저 캐시가 갱신됩니다.

- 진화하면 최대 체력도 늘어남 (진화한 모습의 체력 차이만큼)
- 일반 스타팅: 최소 체력 4칸으로 시작, 관장을 이기면 1칸, 배지 0~3개 구간 보스 체력 x0.8, 초반 보스 공격 빈도 완화 유지
- 전설 스타팅: 상대 체력 x1.5, 관장 보상 체력 반 칸, 보스는 처음부터 제 속도로 공격
- 7·8단계(사천왕·챔피언) 체력 배율 1.85/2.0 → 1.75

### v2.6.5 — 배수 규칙 정리
- 도구의 배수는 얻는 순간 그때 능력치에 한 번, 기술·특성의 배수는 늘 적용되어 그 뒤에 얻은 도구에도 곱해짐
- 지오컨트롤(공격 x1.3·연사·속도), 액셀브레이크·라이트닝드라이브(속도 x1.15), 다이아스톰(급소 +30%·회피 +10%)을 배울 때 한 번 곱하던 방식에서 늘 적용으로 (잊으면 사라짐)

### v2.6.4 — 기술 설명 간략화
- 기술 설명을 "공격 방식 · 핵심 효과"로 짧게 (예: 화염방사 "광선 · 화상", 바늘미사일 "강화 · 3갈래")

### v2.6.3 — 상성 완화, 돌진 기술 조정
- 상성이 나쁠 때 피해 감소 완화: 효과가 별로(0.5배) → 0.75배, 0.25배 → 0.6배, 효과 없음 → 0.5배 (효과가 굉장하면 그대로)
- 돌진 기술(화룡점정·액셀브레이크·라이트닝드라이브): 구르기 대기 0.25초 → 1초, 대신 돌진·충격파 위력에 이동 속도만큼 배수(최소 2배)
- 후파의 고리에서 잡은 전설은 아이템을 떨구지 않음 (판이 바로 끝나므로)
- 전설·환상으로 플레이하면 금빛 전용 오라(빛무리·빛줄기·빛가루), 왼쪽 창 특성 이름 옆에 화력 배수(예: 프레셔 x1.25)

### v2.6.2 — 모바일 가로 전체 화면
- 휴대폰 가로: 게임 화면을 화면 높이에 꽉 채우고, 스틱·버튼은 그 위에 반투명하게 겹침 (아래 도구 줄·안내 문구 숨김)
- 처음 화면을 누르면 전체 화면 + 가로 고정 시도 (안드로이드 크롬 등 지원 브라우저)
- 세로로 들면 "가로로 돌려 주세요" 안내, 누르면 예전 세로 배치로 계속

### v2.6.0 — 모의 플레이테스트 반영 난이도 조정
- 적응 난이도: 잘할 때 상대 체력 최대 6배 → 2.5배, 지수 0.75 → 0.5. 화력이 모자라면 상대 체력을 0.7배까지 낮춰 도와줌
- 관장을 이기면 최대 체력 +반 칸 (배지 8개면 +4칸). 레벨업 체력은 그대로 없음
- 필살기·큰 공격은 약점·각성이 겹쳐도 반 칸까지만 더 아픔 (한 방 최대 2칸)

- **라이벌 결투장**: 라이벌과 마주치면 체육관 같은 결투장으로 옮겨서 싸우고, 이기면 원래 자리로 돌아옴 (보상은 그 자리에)
- **타운맵**: 체육관마다 순서 번호 또는 ✔(배지 획득) 표시, 다음에 갈 체육관이 깜빡이고 아래에 이름·타입·관장 표시
- **챔피언로드 고리**: 배지 8개를 모으면 관장 방에 챔피언로드(없는 지방은 포켓몬리그 마을)로 바로 가는 고리

### v1.7.0 — 후파의 고리 & 보스 패턴
- **후파의 고리**: 챔피언을 이기면 챔피언 방에 후파의 고리가 열림 (옆의 고리를 밟으면 그대로 모험 끝)
  - 들어가면 전용 연출·효과음과 함께 **이공간 결투장**으로 이동, 체력 완전 회복
  - 상대는 **반드시 이로치인 전설·환상의 포켓몬**. 아직 해금하지 못한 포켓몬이 남아 있으면 그중에서만 나옴
  - 체력은 방금 이긴 **챔피언 포켓몬 전원의 체력 합 x1.5**, 기술을 더 자주 이어서 씀
  - 이기면 그 포켓몬(이로치)으로 다음 판을 시작할 수 있음. 져도 챔피언 결과는 그대로
  - 환상의 포켓몬 16종 추가 (지라치, 테오키스, 마나피, 다크라이, 쉐이미, 아르세우스, 비크티니, 케르디오, 메로엣타, 게노세크트, 후파, 볼케니온, 마기아나, 마샤도, 제라오라, 자루도)
- **보스 패턴 5종 추가**: 추적탄, 탄막 벽, 연속 낙하, 분열탄, 휩쓸기 광선. 모두 예고가 있어 피할 수 있음
  - 관장·사천왕은 강할수록 더 많이 씀 (초반 2개 → 중반 4개 → 후반·챔피언 5개), 전설은 전부 쓰고 기술을 이어서 씀
- **기술 능력치가 능력치 창에 보임**: 위력 배수는 공격에, 급소 확률은 급소에, 연사·탄속 변화도 바로 반영 (배우거나 잊을 때 ▲▼ 표시)
- **이로치 보너스**: 이로치로 쓰러뜨린 전설·환상·스타팅(계열마다 하나)마다 다른 포켓몬의 이로치 확률 +1% (메뉴 → 포켓몬에서 확인)
