# 포켓몬 던전 로그

포켓몬 지방을 돌아다니며 배지를 모으고 리그에 도전하는 **비상업 팬게임 로그라이크**입니다.
쓰러지면 처음부터 다시 시작하고, 판을 거듭할수록 도감·도전과제·스타팅 포켓몬·지방이 해금됩니다.

▶ 플레이: https://umgeunchan.github.io/pokemon-roguelike/

> 포켓몬스터와 관련된 이름·그림의 권리는 Nintendo / Creatures / GAME FREAK에 있습니다.
> 이 프로젝트는 수익을 내지 않는 팬 제작물이며, 데이터와 그림은 PokeAPI, PMD SpriteCollab, Pokémon Showdown에서 불러옵니다.

## 조작

| 키 | 동작 |
|---|---|
| W A S D | 이동 (문 앞에서 W를 누르면 건물에 들어감) |
| 방향키 | 그 방향으로 공격 |
| Space | 달리기(대시) |
| E | 말 걸기 · 상점 닫기 |
| M | 지방 지도 |
| Esc | 메뉴 (설정, 볼륨) |
| N | 소리 끄기/켜기 |
| H | 첫 판 안내 건너뛰기 |
| R | 결과 화면에서 다시 하기 |

휴대폰·태블릿에서는 왼쪽 스틱(이동), 오른쪽 스틱(공격)과 화면 버튼으로 조작합니다.

## 파일 구조

```
index.html            캔버스와 스크립트 불러오기 (순서대로 실행되니 순서를 바꾸지 말 것)
css/style.css         화면·터치 버튼 스타일
js/data/regions.js    지방 지도, 체육관 관장, 사천왕, 라이벌, 트레이너 종류
js/data/moves-items.js 타입, 도구, 상점, 기술머신, 숨은 조합, 전설 기술
js/progress.js        지방 해금, 도전과제
js/core.js            공통 도구, 저장소, 전역 상태, 데이터 불러오기, 난이도 상수
js/world.js           지방 지도 생성, 상자·전설 배치, 적 생성
js/run.js             경험치·레벨·진화, 새 판, 이어하기 저장
js/combat.js          피해 계산, 공격, 적 기술 패턴, 야생 출현, 전설
js/battle.js          트레이너·관장·사천왕·챔피언·라이벌 승부, NPC, 상점
js/update.js          매 프레임 진행: 이동, 충돌, 아이템 줍기
js/draw.js            필드 그리기
js/screens.js         메뉴·지방 선택·스타팅 선택·도전과제·결과 화면
js/input.js           키보드·마우스 입력
js/account.js         Google·게스트 계정, Firebase 동기화, 시작 화면
js/touch.js           터치 조작
js/audio.js           합성 배경음과 효과음
js/main.js            게임 루프, 시작
firestore.rules       Firestore 보안 규칙 (자기 문서만 읽고 쓰기)
```

수정 후 배포할 때는 `index.html`의 `?v=` 숫자를 올려야 브라우저 캐시가 갱신됩니다.

## 패치 노트

### v2.3.0 — 기믹: 메가진화·Z기술·다이맥스·테라스탈
- 기믹 아이템은 볼(드물게)·관장/라이벌 보상(35%)·상점 특가에서 나오고, 얻는 순간 영구 적용. 모두 함께 쓸 수 있음
- **메가진화**: 내 진화 계통의 메가스톤만 나옴. 메가진화 가능한 최종 진화면 메가진화(공격 x1.5), 아직이면 진화하는 순간 메가진화. 무지개 고리 이펙트
- **Z크리스탈**: 기술 하나를 골라 Z파워(그 기술 타입 피해 x1.5, 다른 공격 x1.25, 모든 효과 범위 x1.3). 그 기술이 공격 방식의 타입을 정함. 기술을 잊으면 Z파워는 새 기술로
- **다이맥스밴드**: 최대 체력 +3칸, 공격 x1.25, 몸 1.4배 + 붉은 기운
- **테라피스**(타입 18종): 내 타입이면 공격 x1.5, 아니면 공격 +0.8. 머리 위에 테라 보석 왕관

### v2.2.2 — 여러 방향 효과가 모든 공격 방식에
- 유전자쐐기(뒤로 한 번 더), 매지컬샤인(사방), 근원의파동(5갈래)이 보통 탄뿐 아니라 레이저·광선·원뿔·알에도 그 공격 방식 그대로 적용
  - 원뿔은 갈래 대신 넓은 범위로: 매지컬샤인은 내 둘레 전체, 근원의파동은 아주 넓은 원뿔
  - 알은 작은 알로, 광선은 가는 광선으로 (위력은 탄일 때와 같은 비율)

### v2.2.1 — 전설 기술 강화
- **돌진 기술**(화룡점정·브레이브차지·라이트닝드라이브): 돌진 잔상 이펙트(전기는 스파크), 지나가는 길 주변까지 피해, 끝에서 충격파, 적을 맞히면 체력 회복(3마리 이상이면 1칸) + 잠깐 무적
- 섀도다이브: 나타나며 적을 맞히면 체력 회복
- 거대방패돌격: 8초마다 공격 한 번을 완전히 막는 방패 (몸 둘레에 방패 테두리가 보임)
- 자연의분노·카타스트로피 발동 이펙트, 데스윙 흡수 이펙트

### v2.2.0 — 라이벌·체육관 난이도, 필살기
- 라이벌: 첫 승부부터 관장처럼 기술 패턴을 쓰고 동료 1마리 + 스타팅으로 나옴 (첫 승부 체력은 낮게), 이후 라이벌 체력 x1.15
- 관장 체력 초반 보정 완화 (첫 체육관 0.45 → 0.6배 등), 보스급은 초반에도 공격 빈도가 줄지 않음
- 레벨업으로 최대 체력이 오르지 않음 (도구·도핑약으로만)
- **필살기**: 배지 4개부터 관장·라이벌·사천왕·전설이 '필살 일격'(큰 붉은 표식, 따라오는 두 번째 표식)과 '필살 광선'(굵은 광선)을 씀. 맞으면 체력 2칸, 사천왕·챔피언은 3칸. 예고가 길어 피할 수 있음

### v2.1.0 — 같은 종류 공명, 전설 기술 조합
- **같은 종류 공명**: 광선·레이저·원뿔 기술을 같은 종류로 2개 이상 가지면 범위(굵기·길이·원뿔·폭발)와 위력이 오름. 한 쌍마다 범위 x1.25(+0.15)·위력 x1.2(+0.1). 전설의 광선 기술도 광선으로 셈. 구슬은 원래대로 구슬끼리 커짐
- **전설 기술 조합 20개 추가** (숨은 조합 총 53개): 전설 기술과 어울리는 일반 기술을 함께 가지면 켜짐

### v2.0.0 — 기술 개편: 광선·레이저·원뿔·구슬
- **공격 방식 4가지** (우선순위: 알폭탄 > 광선 > 레이저 > 원뿔 > 보통 탄). 공격 방식이 되지 못한 기술도 적중 효과는 그대로 얹힘
  - **광선** (누르고 떼는 충전형): 화염방사·파괴광선·용의파동·하이드로펌프·번개. 가장 최근에 배운 광선의 타입으로 나감
  - **레이저** (아이작의 테크놀로지처럼 가늘고 긴 선을 연사, 닿은 적을 모두 꿰뚫음): 10만볼트(전기)·냉동빔(얼음). 광선과 함께면 광선에 감겨 효과가 얹힘
  - **원뿔** (탄 대신 앞쪽 부채꼴 범위): 얼다바람·지진·파도타기·매지컬샤인·스톤샤워·눈보라·벌레의야단법석·대지의힘
  - **구슬** (아주 큰 둥근 탄, 맞으면 폭발, 연사 느려짐): 러스터캐논·섀도볼·기합구슬·문포스·에너지볼. 구슬 + 다른 기술이 있으면 모든 효과가 커지고 위력 증가
- 도깨비불·오물폭탄: 모든 공격에 불·독이 얹힘 (화상·독은 따로 쌓이고, 둘 다 있으면 맹독)
- 전기자석파: 옆의 적에게 전기가 튀고 25% 마비 / 시저크로스: 꿰뚫을 때마다 피해 2배(최대 16배)
- 에어슬래시: 날카로운 칼날, 탄속·연사 증가, 풀죽음 / 치근거리기: 인파이트와 같은 효과 / 인파이트: 연사 감소 없앰
- 매지컬샤인: 유전자쐐기가 있으면 사방 빛이 매 공격마다
- 삭제: 기가드레인, 제비반환, 깨트리기, 아이언헤드, 독찌르기
- 숨은 조합 33개로 정리 (사이코키네시스 조합 5개, 번개 조합 2개 추가, 삭제된 기술의 조합은 다른 기술로)
- 기술 목록이 바뀌어 예전 이어하기 기록은 이어할 수 없음

### v1.9.3 — 보스 멈춤 면역 & 후반 체력 완화
- **보스급 멈춤 면역**: 관장·사천왕·챔피언·전설이 풀죽음·마비·얼음 등으로 합쳐서 1.5초 멈추면, 4초 동안 멈추지 않고 기술을 이어 감 (발밑에 금빛 고리)
- **후반 체력 완화**: 모든 상대 체력 x1.5를 취소. 초반(배지 0~3개)은 지금 난이도 그대로, 마지막 단계 체력은 x2.1 → x1.4
- 긴 대사·알림이 화면 밖으로 잘리지 않게 줄바꿈 (대사창이 위로 늘어남)

### v1.9.2 — 버그 수정
- 🐛 사천왕 방에서 첫 포켓몬이 나오는 순간 게임이 멈추던 버그 수정 (모든 지방)

### v1.9.1 — 난이도 곡선
- 자속(1.5배)에 맞춰 **모든 상대 체력 x1.5**
- 단계(배지 수·지역 깊이)별 난이도 곡선: **초반은 부드럽게, 후반은 거세게**
  - 체력: 첫 단계 x0.85 → 중반 x1 → 마지막 단계 x1.4 (위의 x1.5에 더 곱함)
  - 관장·전설 기술 대기 시간: 첫 단계 x1.2(뜸하게) → 마지막 단계 x0.8(자주)
- 화력 따라가기 기준에 자속을 넣어, 자속으로 오른 화력 때문에 보스 체력이 한 번 더 오르지 않게 함

### v1.9.0 — 기술 고유 효과 & 자속 보정
- **자속 보정**: 내 포켓몬과 같은 타입의 기술을 갖고 있으면 그 타입 공격 **x1.5** (능력치 창의 공격에 반영, 기술 옆에 "자속" 표시)
- **유도 기술(스피드스타·사이코 계열)이 모든 공격에 적용**: 알폭탄은 날아가며 목표를 따라가고, 알에서 터져 나온 광선도 휜다
- **능력치만 바꾸던 기술에 고유 효과 추가** (능력치 보너스는 그대로)
  - 러스터캐논: 5번째 공격마다 관통하는 강철 포탄 / 드래곤크루: 맞힌 적과 옆 적을 한 번 더 할퀸다
  - 하이드로펌프: 적을 멀리 밀어내고 벽에 부딪히면 추가 피해 / 인파이트: 가까운 적에게 x1.4 더
  - 기합구슬: 큰 탄이 맞은 자리에서 터진다 / 제비반환: 탄이 장애물을 넘어간다
  - 스톤에지: 급소 시 바위 칼날 / 깨물어부수기: 물린 적은 3초 동안 받는 피해 +20%
  - 치근거리기: 15% 헤롱헤롱 / 깨트리기: 기술을 준비하는 적을 맞히면 기술이 끊긴다
  - 문포스: 20% 확률로 적의 공격이 뜸해진다 / 대지의힘: 25% 확률로 발밑에서 땅이 솟는다 / 씨기관총: 씨앗이 흩어진다
  - 지오컨트롤: 12초마다 4초 동안 피해 x1.5 / 다이아스톰: 30% 확률로 다이아 파편 / 메테오드라이브·거대검돌격: 탄이 관통
- **숨은 조합 12개 추가** (모두 26개)
- **공격 색**: 최근에 배운 두 기술의 타입 색으로 탄·광선·알 색이 바뀌고, 조합이 켜지면 조합 고유의 색이 된다

### v1.8.0 — 넓어진 도로 & 라이벌 결투장
- **지도 크기 조정**: 마을은 약 40% 작게(건물과 NPC만 들어가는 크기), 도로 구역은 더 길고 넓게, 장소 사이 길도 폭 5칸 → 7칸
  - 넓어진 도로에 맞춰 야생 포켓몬이 한 번에 더 많이 나오고, 트레이너·볼도 조금 늘어남
  - 지도 규칙이 바뀌어 예전 이어하기 기록은 이어할 수 없음
- **전설에게서 도망치기**: 전설은 그 장소 안에서만 싸울 수 있고, 장소 밖으로 나가면 "~에게서 도망쳤다!"
  - 전설의 체력은 깎인 그대로 남아서 다시 들어가면 이어서 싸움 (이어하기 기록에도 남음)
  - 전설과 싸우는 동안에는 트레이너·라이벌이 승부를 걸지 않음
- **라이벌 결투장**: 라이벌과 마주치면 체육관 같은 결투장으로 옮겨서 싸우고, 이기면 원래 자리로 돌아옴 (보상은 그 자리에)
- **타운맵**: 체육관마다 순서 번호 또는 ✔(배지 획득) 표시, 다음에 갈 체육관이 깜빡이고 아래에 이름·타입·관장 표시
- **챔피언로드 고리**: 배지 8개를 모으면 관장 방에 챔피언로드(없는 지방은 포켓몬리그 마을)로 바로 가는 고리

### v1.7.0 — 후파의 고리 & 보스 패턴
- **후파의 고리**: 챔피언을 이기면 챔피언 방에 후파의 고리가 열림 (옆의 고리를 밟으면 그대로 모험 끝)
  - 들어가면 전용 연출·효과음과 함께 **이공간 결투장**으로 이동, 체력 완전 회복
  - 상대는 **반드시 이로치인 전설·환상의 포켓몬**. 아직 해금하지 못한 포켓몬이 남아 있으면 그중에서만 나옴
  - 체력은 방금 이긴 **챔피언 포켓몬 전원의 체력 합 x1.5**, 기술을 더 자주 이어서 씀
  - 이기면 그 포켓몬(이로치)으로 다음 판을 시작할 수 있음. 져도 챔피언 결과는 그대로
